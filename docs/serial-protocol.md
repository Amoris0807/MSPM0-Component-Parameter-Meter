# 串口协议

串口配置：`9600 baud, 8 data bits, no parity, 1 stop bit`。命令以回车或换行结束。

| 命令 | 功能 |
|---|---|
| `F1` 至 `F100000` | 设置 AD9833 正弦频率，单位 Hz |
| `R0` | 关闭全部量程继电器 |
| `R1` | 选择 4.7 Ω 参考电阻 |
| `R2` | 选择 47 Ω 参考电阻 |
| `R3` | 选择 470 Ω 参考电阻 |
| `R4` | 选择 4.7 kΩ 参考电阻 |
| `A1` | 启用自动量程，只使用 R1 和 R3 |
| `A0` | 关闭自动量程，保留当前量程 |
| `M1` | 启用每 500 ms 一次的测量输出 |
| `M0` | 停止周期测量输出 |
| `?` | 显示帮助 |

示例：

```text
F1000
OK: sine frequency = 1000 Hz
R3
OK: auto range disabled; selected 470 ohm (R3) range
```

测量输出：

```text
exc_dc_mV:1642,sense_dc_mV:1651,exc_pp_mV:592,sense_pp_mV:48,C_nF:...,D:...,Z_re_mohm:...,Z_im_mohm:...,spc_x100:...
```

字段：

| 字段 | 含义 |
|---|---|
| `exc_dc_mV` | 激励通道直流中心值 |
| `sense_dc_mV` | 检测通道直流中心值 |
| `exc_pp_mV` | 激励通道估算峰峰值 |
| `sense_pp_mV` | 检测通道估算峰峰值 |
| `C_nF` | 实验性电容计算结果 |
| `D` | 实验性损耗因数 |
| `Z_re_mohm` | 复阻抗实部，mΩ |
| `Z_im_mohm` | 复阻抗虚部，mΩ |
| `spc_x100` | 每周期采样点数乘以 100 |

未选择参考电阻或计算条件不满足时，阻抗相关字段输出 `NA`。
