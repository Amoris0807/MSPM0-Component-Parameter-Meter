# 测试记录

## 已确认结果

- AD9833 在已测试频率点输出稳定，典型幅度约 608 mVpp，波形基本无明显失真。
- 模拟前端 3.3 V、5 V 与 VCM 测试点曾确认正常，VCM 约 1.65 V。
- R1 与 R3 的继电器控制链路可工作。
- 220 nF 薄膜电容由实验室仪器测得约 222 nF。
- 在 `1 kHz + R2` 的一次幅值测试中，激励约 568 mVpp、检测约 311 mVpp；该数据不能作为最终精度结论，因为 R2 链路阻值存在疑问。
- 最新固件已通过 J-Link 写入并校验。

## 待验证

- 最新 DMA 同步采样与复阻抗输出尚缺少完整串口实测记录。
- R1/R3 自动量程需要覆盖 1 nF 至 100 nF 的标准电容组。
- 每档至少需要开路、短路和标准件校准。
- 需要统计重复性、频率误差、幅值误差以及温漂。
- 电感和 Q 值算法尚未完成。

## 建议测试表

对每个标准电容记录：

```text
标准值, 测试频率, 自动选择量程, C_nF, D, Z_re_mohm,
Z_im_mohm, 重复次数, 平均值, 最大误差
```

每个点建议至少重复 10 次，并保留原始串口输出。
